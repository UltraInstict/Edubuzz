Detailed Findings

Intentionality Watch 7/10

Evidence: Design system is mostly deliberate: green-800 primary, gray-200 borders, rounded-md, Inter font, consistent card pattern. Nav is clean.

Issue: Dual color naming system. Rewritten pages use standard Tailwind (text-gray-900, text-green-800). 18 unrewritten pages still use custom aliases (text-navy, text-muted, border-border, bg-accent). Both render via @theme mapping, but the split system is a maintenance hazard.

Prescription

Migrate 18 remaining pages from custom aliases to standard Tailwind classes. One find-and-replace pass: text-navy → text-gray-900, text-muted → text-gray-600, border-border → border-gray-200, bg-accent → bg-green-800.

Readability Healthy 9/10

Evidence: Body text is text-sm with leading-relaxed. H1 is text-2xl font-bold, H2 is text-xl font-semibold. Content pages use max-w-2xl (672px) — within 60-76ch measure. JobCard hierarchy: text-base title, text-sm company, text-xs meta. Sidebar titles are text-xs uppercase tracking-wide.

Consistent and readable across all audited pages.

Usability Healthy 8/10

Evidence: Homepage has search + province filter + job type pills + listings + sidebar. Post a Job has complete form with pricing context. Contact has form with subject dropdown. Login/Register are functional. Empty states are present in templates.

Note: "0 active jobs" displayed in stats bar undermines trust — this is a data issue (PocketBase has no active jobs), not a design issue. The empty state template IS rendered when jobs.length === 0.

Responsiveness Watch 6/10

Evidence: Nav uses md: breakpoints. Grid layouts collapse at lg:. Pricing and footer grids collapse at md:. All correct.

Issue 1: Post a Job form uses grid-cols-2 for field pairs with no responsive fallback. On 375px viewport, two fields side by side get ~170px each — too narrow for text input. Should be grid-cols-1 sm:grid-cols-2.

Issue 2: Homepage search bar uses flex without flex-wrap. On narrow viewports, input + select + button may overflow horizontally.

Prescription

Add grid-cols-1 sm:grid-cols-2 to all 2-column form grids in post-job.astro. Add flex-wrap to search bar forms on index.astro and jobs/index.astro.

Speed Healthy 9/10

Evidence: CSS properly generated via Tailwind v4 + @tailwindcss/vite. Layout.css is 22.3KB with all utilities present. Loaded via link tag in head. Inter font loaded with print/onload trick + noscript fallback. No large images. Pages are SSR — HTML arrives complete.

Accessibility Critical 3/10

Critical 1 — Insufficient focus styles. All form inputs use focus:outline-none focus:border-green-800. Removing the default outline and replacing with only a border color change does not meet WCAG 2.4.7. Keyboard users cannot see where they are.

Critical 2 — Homepage search has no label. Search input has placeholder but no label element or aria-label. Province select and search button also lack labels. Screen reader users have no programmatic label.

Critical 3 — No skip-to-content link. Keyboard users must tab through nav, stats bar, and ad slot before reaching content.

Issue 4 — Low contrast ad label. text-gray-400 on bg-gray-50 is ~2.5:1 contrast, below 4.5:1 minimum.

Prescription
  1. Replace focus:outline-none with focus:outline-none focus:ring-2 focus:ring-green-800 focus:ring-offset-1 on all inputs and buttons.
  2. Add aria-label to homepage search input, province select, and search button.
  3. Add a skip-to-content link at top of body in Layout.astro.
  4. Change ad slot label from text-gray-400 to text-gray-500.

Summary

The interface is structurally sound. Typography, layout, and container systems are consistent across rewritten pages. Two critical accessibility issues: insufficient focus styles and missing form labels. Two watch items: 18 pages need color alias migration, and form grids need mobile fallbacks. Speed and readability are healthy.

Next move: Fix accessibility criticals first (focus rings, labels, skip link). Then migrate the 18 remaining pages from custom color aliases to standard Tailwind classes. Then add responsive form grid fallbacks.
