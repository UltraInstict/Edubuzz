# Edubuzz.co.za — Complete Setup Guide

## Stack
- **Frontend**: Astro 4 (SSR, Node adapter)
- **Backend**: PocketBase (Go binary, SQLite, auto REST API)
- **Styling**: Tailwind CSS
- **AI**: Anthropic Claude Haiku (job description generation)
- **Hosting**: Ubuntu VPS (Hetzner CX22 ~R90/month)

---

## DAY 1 — Local Development

### 1. Prerequisites
```bash
# Install Node.js 20+ from https://nodejs.org
node --version   # must be 20+

# Install VS Code from https://code.visualstudio.com
```

### 2. Set up Astro
```bash
cd edubuzz
npm install
```

### 3. Set up PocketBase
```bash
# Download PocketBase for your OS from https://pocketbase.io/docs/
# Linux:
wget https://github.com/pocketbase/pocketbase/releases/latest/download/pocketbase_linux_amd64.zip
unzip pocketbase_linux_amd64.zip
./pocketbase serve
# Open http://localhost:8090/_/ — create your admin account
```

### 4. Configure environment
```bash
cp .env.example .env
# Edit .env — add your ANTHROPIC_API_KEY from console.anthropic.com
```


## DAY 3 — Production VPS Deployment

### 1. Provision VPS
- Hetzner CX22: 2 vCPU, 4GB RAM, 40GB SSD — ~R90/month
- Choose Ubuntu 22.04
- Add your SSH key during setup

### 2. Initial server setup
```bash
ssh root@YOUR_VPS_IP

# Update system
apt update && apt upgrade -y

# Install Node 20
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt-get install -y nodejs

# Install pm2
npm install -g pm2

# Install Nginx
apt install -y nginx certbot python3-certbot-nginx

# Create app user
useradd -m -s /bin/bash edubuzz
su - edubuzz
```

### 3. Deploy PocketBase
```bash
mkdir ~/pocketbase && cd ~/pocketbase
wget https://github.com/pocketbase/pocketbase/releases/latest/download/pocketbase_linux_amd64.zip
unzip pocketbase_linux_amd64.zip && rm pocketbase_linux_amd64.zip
mkdir pb_hooks
cp /path/to/edubuzz/pb_hooks/main.pb.js pb_hooks/

# Create systemd service
sudo nano /etc/systemd/system/pocketbase.service
```

```ini
[Unit]
Description=PocketBase
After=network.target

[Service]
Type=simple
User=edubuzz
WorkingDirectory=/home/edubuzz/pocketbase
ExecStart=/home/edubuzz/pocketbase/pocketbase serve --http=127.0.0.1:8090
Restart=on-failure
RestartSec=5s

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable pocketbase
sudo systemctl start pocketbase
# Admin UI: http://YOUR_VPS_IP:8090/_/ (temporarily open port 8090 in firewall)
```

### 4. Deploy Astro
```bash
# On your local machine — build first
npm run build

# Upload to VPS (scp or rsync)
rsync -avz --exclude node_modules --exclude .git . edubuzz@YOUR_VPS_IP:~/edubuzz/

# On VPS
cd ~/edubuzz
npm install --production
cp .env.example .env
nano .env  # fill in PB_URL=http://127.0.0.1:8090 and ANTHROPIC_API_KEY

# Start with pm2
pm2 start npm --name edubuzz -- start
pm2 save
pm2 startup  # follow the instructions it prints
```

### 5. Nginx + SSL
```bash
# Copy nginx config
sudo cp ~/edubuzz/nginx.conf /etc/nginx/sites-available/edubuzz
sudo ln -s /etc/nginx/sites-available/edubuzz /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

# SSL with Let's Encrypt (free)
sudo certbot --nginx -d edubuzz.co.za -d www.edubuzz.co.za
```

### 6. Point DNS
In your domain registrar (wherever edubuzz.co.za is registered):
- Add A record: `@` → YOUR_VPS_IP
- Add A record: `www` → YOUR_VPS_IP
- Wait 5–15 minutes for propagation

### 7. Post-launch
```bash
# Submit sitemap to Google Search Console
# https://search.google.com/search-console
# Add property: edubuzz.co.za
# Submit: https://edubuzz.co.za/sitemap.xml

# Monitor logs
pm2 logs edubuzz
sudo journalctl -u pocketbase -f
```

## Email (SMTP) Setup — for job alerts and application confirmations
In PocketBase admin → Settings → Mail:
- Use **Brevo** (free tier: 300 emails/day) or **Mailgun**
- SMTP host: smtp-relay.brevo.com
- Port: 587
- Username: your Brevo login
- Password: your Brevo SMTP key

## Adding AI descriptions — quick reference
The `/api/generate-description` endpoint calls Claude Haiku.
Cost: ~R0.003 per description. For 1,000 job descriptions = ~R3.

To use Gemini (free) instead, change the API URL in `src/pages/api/generate-description.ts`:
```
https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent
```
